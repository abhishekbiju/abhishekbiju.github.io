Privacy Policy

Effective date: August 3, 2026

FocusFuse is a local-first focus timer and distraction guard. It has no account system, backend service, advertising, analytics SDK, or telemetry.

Data FocusFuse handles

FocusFuse stores the following information locally in the user's browser:

  • focus intentions and a bounded list of recent intentions;
  • timer, Pomodoro, guard, notification, and sound settings;
  • user-selected guarded domains and per-interval exceptions;
  • focus interval timestamps, planned and actual focused duration, mode, outcome, guard choice, and an optional abandonment category;
  • streak, daily and weekly focus summaries, and aggregate guard-intervention counts.

On a domain for which the user explicitly grants Chrome site access, FocusFuse temporarily reads the current hostname to decide whether to display the distraction guard. It does not read or store page content, URL paths, page titles, form data, or a history of pages visited.

How data is used

This information is used only to provide FocusFuse's user-facing timer, distraction guard, recovery, history, streak, and local analytics features.

Storage and retention

All data is stored in chrome.storage.local on the user's device. FocusFuse does not transmit it to the developer or any third party. Data remains until the user clears it in FocusFuse, removes the extension, or replaces settings and history by importing a backup.

Users may export a local JSON backup. Exported files are created only at the user's request and are controlled by the user.

Sharing and sale

FocusFuse does not sell, rent, share, or transfer user data. It does not use user data for advertising, credit decisions, or purposes unrelated to its single purpose.

Permissions

FocusFuse requests browser permissions only for local storage, timer alarms, completion notifications and sound, toolbar and tab coordination, and distraction guards. Website access is optional and requested only for domains selected by the user. A permission can be denied or revoked through Chrome at any time.

Limited Use

FocusFuse's use of information received from Chrome APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Chrome API data is used only to provide or improve FocusFuse's single user-facing purpose.

Changes

Material changes to these practices will be reflected in this policy and disclosed through the extension or its store listing before changed data handling begins.
